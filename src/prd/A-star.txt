Project Title

A* Search Algorithm Visualizer for Graphs

1️⃣ Overview
🔍 Summary

Build a web-based interactive visualizer that demonstrates how the A* search algorithm works on a graph (or grid).

The user can:

Create or load a graph

Select a start and goal node

Choose a heuristic function

Watch A* explore the graph step-by-step:

which nodes go into open list

which nodes go into closed list

how g, h, f values are calculated

See the final shortest path highlighted.

🎯 Purpose

This tool is meant to teach A* on a general graph, not just specific puzzles (8-puzzle, missionaries, etc.).
It helps juniors understand:

How A* combines cost (g) + heuristic (h)

How nodes are picked from the open list

Why A* is optimal (with admissible heuristics)

Perfect for:

AI Lab demo

Viva explanations

Online learning tool (hosted on Netlify)

2️⃣ Objectives

Implement A* on a weighted graph (non-negative edge weights).

Let users visually build or edit a graph.

Visualize the search process (open list, closed list, current node).

Support at least one admissible heuristic:

Euclidean distance / straight-line distance (for coordinate-based nodes)

Show final shortest path clearly.

4️⃣ Algorithm Details
Graph Model

Nodes: id, x, y

Edges: from, to, weight

Represent as adjacency list:

graph = {
  "A": [{to: "B", w: 2}, {to: "C", w: 5}],
  "B": [{to: "C", w: 1}, ...],
};

A* Algorithm Pseudocode
function A*(start, goal):
    openSet = priority queue ordered by f
    openSet.push(start)
    g[start] = 0
    h[start] = heuristic(start, goal)
    f[start] = g[start] + h[start]
    parent[start] = None

    while openSet not empty:
        current = node in openSet with lowest f

        if current == goal:
            return reconstruct_path(parent, goal)

        move current from openSet to closedSet

        for each neighbor of current:
            tentative_g = g[current] + weight(current, neighbor)

            if neighbor in closedSet and tentative_g >= g[neighbor]:
                continue

            if neighbor not in openSet or tentative_g < g[neighbor]:
                parent[neighbor] = current
                g[neighbor] = tentative_g
                h[neighbor] = heuristic(neighbor, goal)
                f[neighbor] = g[neighbor] + h[neighbor]
                if neighbor not in openSet:
                    openSet.push(neighbor)
